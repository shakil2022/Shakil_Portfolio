title: Software Engineering

description: This course introduces the fundamental concepts, methods, tools, and procedures of software engineering. Students will learn software processes, life-cycle models, requirements engineering, software analysis and design, implementation, testing, quality assurance, design patterns, and software project management.

instructor: Md. Shakil Ahmed

year: 2026

term: Spring

importance: 3

course_id: cse-327-software-engineering

schedule:

* week: 1
  date: Week 1
  topic: Introduction to Software Engineering
  description: Introduction to software, software engineering, software products, essential software attributes, software engineering ethics, legacy software, software process layers, framework activities, and software myths.

* week: 2
  date: Week 2
  topic: Software Processes and Process Models
  description: Introduction to software processes, process descriptions, plan-driven and agile processes, Waterfall, V-Model, Incremental, and reuse-oriented software development models.

* week: 3
  date: Week 3
  topic: Agile Software Development
  description: Software prototyping, Spiral model, Rational Unified Process, Agile principles, Agile modeling, Agile Unified Process, Extreme Programming, refactoring, and pair programming.

* week: 4
  date: Week 4
  topic: Requirements Engineering
  description: Introduction to requirements engineering, functional and non-functional requirements, requirements documentation, specification, elicitation, analysis, validation, and requirements management.

* week: 5
  date: Week 5
  topic: Scenario-Based and Class-Based Modeling
  description: Development of Use Case, Activity, and Swim Lane diagrams along with Class Diagrams, CRC cards, and analysis packages.

* week: 6
  date: Week 6
  topic: Behavioral Modeling
  description: Introduction to behavioral models including State Diagrams and Sequence Diagrams for representing system behavior and interactions.

* week: 7
  date: Week 7
  topic: Architectural Design
  description: Introduction to software architectural design, architectural views, architectural patterns, and software architecture principles.

* week: 8
  date: Week 8
  topic: Software Design and Design Patterns
  description: Study of software design principles, modularity, abstraction, design strategies, and commonly used software design patterns.

* week: 9
  date: Week 9
  topic: Software Implementation and Reuse
  description: Software implementation practices, component reuse, software development environments, and implementation-related design considerations.

* week: 10
  date: Week 10
  topic: Software Testing
  description: Introduction to software testing principles, testing strategies, unit testing, integration testing, system testing, and test case development.

* week: 11
  date: Week 11
  topic: Software Quality Assurance
  description: Software quality concepts, quality assurance activities, verification and validation, software standards, and quality management.

* week: 12
  date: Week 12
  topic: Software Maintenance and Evolution
  description: Software evolution, maintenance processes, legacy systems, software change, and techniques for maintaining software systems.

* week: 13
  date: Week 13
  topic: Software Configuration and Project Management
  description: Introduction to software configuration management, version control, project organization, planning, scheduling, and management activities.

* week: 14
  date: Week 14
  topic: Software Risk and Project Planning
  description: Software project planning, risk management, resource allocation, project scheduling, and software project management techniques.

* week: 15
  date: Week 15
  topic: Software Metrics and Estimation
  description: Process and product metrics, project metrics, software measurement, software project estimation, resources, and estimation techniques.

* week: 16
  date: Week 16
  topic: Brainstorming and Project Development
  description: Brainstorming activities, software project development, problem-solving, project discussion, and preparation for the final examination.

* week: 17
  date: Week 17
  topic: Case Study and Final Review
  description: Comprehensive case studies, problem-solving activities, course review, questions and answers, and preparation for the semester final examination.

Software Engineering

This course introduces the fundamental concepts, methods, tools, and procedures of software engineering. Students will learn software processes, life-cycle models, requirements engineering, software analysis and design, implementation, testing, quality assurance, design patterns, and software project management.

Instructor: Md. Shakil Ahmed
Year: 2026
Term: Spring

Course Schedule

Week 1
Introduction to Software Engineering

Introduction to software, software engineering, software products, essential software attributes, software engineering ethics, legacy software, software process layers, framework activities, and software myths.

Week 2
Software Processes and Process Models

Introduction to software processes, process descriptions, plan-driven and agile processes, Waterfall, V-Model, Incremental, and reuse-oriented software development models.

Week 3
Agile Software Development

Software prototyping, Spiral model, Rational Unified Process, Agile principles, Agile modeling, Agile Unified Process, Extreme Programming, refactoring, and pair programming.

Week 4
Requirements Engineering

Introduction to requirements engineering, functional and non-functional requirements, requirements documentation, specification, elicitation, analysis, validation, and requirements management.

Week 5
Scenario-Based and Class-Based Modeling

Development of Use Case, Activity, and Swim Lane diagrams along with Class Diagrams, CRC cards, and analysis packages.

Week 6
Behavioral Modeling

Introduction to behavioral models including State Diagrams and Sequence Diagrams for representing system behavior and interactions.

Week 7
Architectural Design

Introduction to software architectural design, architectural views, architectural patterns, and software architecture principles.

Week 8
Software Design and Design Patterns

Study of software design principles, modularity, abstraction, design strategies, and commonly used software design patterns.

Week 9
Software Implementation and Reuse

Software implementation practices, component reuse, software development environments, and implementation-related design considerations.

Week 10
Software Testing

Introduction to software testing principles, testing strategies, unit testing, integration testing, system testing, and test case development.

Week 11
Software Quality Assurance

Software quality concepts, quality assurance activities, verification and validation, software standards, and quality management.

Week 12
Software Maintenance and Evolution

Software evolution, maintenance processes, legacy systems, software change, and techniques for maintaining software systems.

Week 13
Software Configuration and Project Management

Introduction to software configuration management, version control, project organization, planning, scheduling, and management activities.

Week 14
Software Risk and Project Planning

Software project planning, risk management, resource allocation, project scheduling, and software project management techniques.

Week 15
Software Metrics and Estimation

Process and product metrics, project metrics, software measurement, software project estimation, resources, and estimation techniques.

Week 16
Brainstorming and Project Development

Brainstorming activities, software project development, problem-solving, project discussion, and preparation for the final examination.

Week 17
Case Study and Final Review

Comprehensive case studies, problem-solving activities, course review, questions and answers, and preparation for the semester final examination.

Course Overview

This course provides a comprehensive introduction to software engineering principles and practices. By the end of this course, students will be able to:

  • Understand fundamental software engineering concepts, software architecture, software quality, and project scheduling.
  • Analyze software engineering problems using appropriate tools, techniques, and methodologies.
  • Apply software engineering models and techniques to develop effective real-world software solutions.
  • Design and implement software solutions using appropriate software engineering principles, methodologies, tools, and techniques.

Prerequisites

  • CSE 317
  • Basic programming and problem-solving knowledge
  • Familiarity with fundamental computer science concepts

Textbooks

  • Primary: Software Engineering by Ian Sommerville, 9th Edition.
  • Reference: Software Engineering: A Practitioner's Approach by Roger S. Pressman.
  • Reference: Fundamentals of Software Engineering by R. Mall.
  • Reference: An Integrated Approach to Software Engineering by P. Jalote.

Online Resources

  • Stanford University Software Engineering
  • MIT OpenCourseWare - Foundations of Software Engineering

Grading

  • Class Participation and Activity: 5%
  • Class Tests: 15%
  • Assignment/Report and Presentation: 10%
  • Midterm Examination: 30%
  • Final Examination: 40%

Total: 100%

Course Overview

This laboratory course emphasizes practical cybersecurity and digital forensic skills through controlled laboratory environments. Students will configure security testing environments, examine common vulnerabilities, perform security assessments, analyze digital artifacts, and investigate simulated security incidents.

Laboratory activities cover web application security, Python-based security tasks, cryptography, information gathering, reverse engineering, binary analysis, digital forensics, and responsible cybersecurity practices. All practical activities are conducted in authorized and controlled environments.

Course Learning Outcomes

CLO1 — Cybersecurity Fundamentals

Understand fundamental cybersecurity concepts, common vulnerabilities, security threats, and responsible security practices.

CLO2 — Security Testing

Apply appropriate tools and techniques to perform controlled vulnerability assessment, web application security testing, and penetration testing exercises.

CLO3 — Security Analysis

Analyze security incidents, system information, digital artifacts, and binary files using appropriate cybersecurity and analysis techniques.

CLO4 — Digital Forensic Investigation

Apply digital forensic techniques to acquire, examine, analyze, and interpret digital evidence in controlled investigation scenarios.

Course Schedule

Week Topic Description
1 Cybersecurity Laboratory Setup Introduction to the cybersecurity laboratory environment, VMware, Kali Linux installation and configuration, and basic security tools.
2 Burp Suite and DVWA Configuration of Burp Suite and DVWA for controlled web application security testing and vulnerability analysis.
3 Web Application Security Testing Practical study of common web application vulnerabilities, including SQL injection, cross-site scripting, CSRF, clickjacking, and file upload vulnerabilities in controlled environments.
4 Python Scripting for Cybersecurity Introduction to Python scripting for security tasks, including network scanning, file analysis, and security automation in controlled laboratory environments.
5 Cryptography and Information Gathering Practical exercises involving encryption, decryption, hashing, OSINT, Shodan, IP lookup, and information-gathering techniques.
6 Reverse Engineering and Binary Analysis Introduction to reverse engineering using Ghidra and related tools, with practical exercises involving binary analysis and common memory-related vulnerabilities.
7 Digital Forensics and Cyber Law Introduction to digital forensic investigation, evidence handling, ethical and legal considerations, and responsible use of cybersecurity tools.
8 Final Project and Practical Evaluation Practical project evaluation covering security testing, incident analysis, digital forensic techniques, and responsible cybersecurity practices.

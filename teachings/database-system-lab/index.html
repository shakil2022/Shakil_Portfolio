Course Overview

This laboratory course provides students with practical experience in designing, creating, modifying, and managing relational database systems. The course is based on CSE 207: Database Management Systems and focuses on the practical implementation of database concepts using SQL and relational database management systems.

By the end of this course, students will be able to:

  • Demonstrate the use of a relational database management system to create, secure, populate, and maintain databases.
  • Apply SQL commands to create and modify database structures.
  • Perform data manipulation operations, including insertion, deletion, and updating of records.
  • Design and execute SQL queries using selection, projection, restrictions, joins, grouping, and subqueries.
  • Implement database constraints, indexes, views, and triggers.
  • Design relational databases and develop ER diagrams for real-world applications.
  • Develop a database application using a relational database management system.
  • Demonstrate teamwork, problem-solving, and project management skills through a database project.

Course Learning Outcomes

CLO1 — Database Fundamentals

Demonstrate the use of a relational database management system to create, secure, populate, and maintain relational databases.

CLO2 — SQL Programming

Apply SQL commands to create and modify database structures and perform data manipulation and retrieval operations.

CLO3 — Query Development

Design and execute SQL queries using selection, projection, restrictions, joins, grouping, aggregate functions, and subqueries.

CLO4 — Database Application Development

Design relational databases, develop ER diagrams, implement database structures, and develop a database application for a real-world problem.

Course Schedule

Week Topic Description
1 Introduction to Database Systems and SQL Introduction to relational database management systems, database creation, SQL environments, and the basic structure of relational databases.
2 Data Definition Language Practical implementation of CREATE, ALTER, and DROP statements to create and modify databases and tables.
3 Data Manipulation Language Practical implementation of INSERT, DELETE, and UPDATE statements to populate and modify database records.
4 Selection, Projection, and Restrictions Implementation of SELECT statements, selection and projection operations, filtering records, and applying restrictions using SQL.
5 Joins Practical implementation of inner joins, outer joins, and other join operations to retrieve data from multiple related tables.
6 Grouping and Aggregate Functions Implementation of GROUP BY, HAVING, and aggregate functions to summarize and analyze database records.
7 Midterm Review and Examination Review of SQL concepts and laboratory exercises covered during the first six weeks, followed by the midterm laboratory examination.
8 Project Proposal and Database Design Submission and finalization of project proposals, identification of entities and relationships, and introduction to database design and ER diagrams.
9 Subqueries Practical implementation of single-row and multiple-row subqueries, nested queries, and subqueries within SELECT, WHERE, and FROM clauses.
10 Indexes Introduction to database indexes, index creation, and practical implementation to improve query performance.
11 Database Design and ER Diagrams Supervision of database design, ER diagram development, relational schema design, and implementation of database structures for the project.
12 Views Practical implementation of views, creation of virtual tables, and execution of queries through views.
13 Triggers Introduction to database triggers and practical implementation for automated database operations and data integrity.
14 Final Project Development Development of the final database application, implementation of SQL operations through a user interface, and supervision of project progress.
15 Final Project Evaluation Evaluation of the final database project, demonstration of database functionality, and assessment of project implementation.
16 Brainstorming and Problem Solving Intensive discussion, brainstorming, and problem-solving activities to strengthen database design and SQL skills.
17 Final Project Evaluation and Review Final project evaluation, comprehensive review of database concepts, questions and answers, and preparation for final assessment.
